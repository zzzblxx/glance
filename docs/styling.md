# 显示布局

设备与本机预览共用 `firmware/e1003/include/dashboard.h`。Mac 只发送数据，字号、字重、
布局、字库和横幅都在设备端；更改这些内容后需构建、刷写匹配固件。

## 首页

画布为 1404 × 1872 竖屏，左右边距 64 px，16 级灰度。

| 区域 | 规则 |
| --- | --- |
| 标题 | 数据传入，当前为 `ChatGPT`；184 px、6 px 水平笔画扩展；其他文字为 2 px |
| 右上 | 日期 44 px、星期 80 px；不显示实时分钟时钟 |
| 分隔线 | `y=228`，3 px 黑线，左右与内容区对齐，位于头部和额度区之间 |
| 额度 | 同一分组的 5 小时与 7 天左右平分；确定仅有 7 天窗口时使用整行 |
| 横幅 | 704 × 176，左上角 `(64,512)`，整张图片内置 |
| 重置机会 | 图片右侧单独绘制圆箭头、次数与到期信息 |
| 便签 | 四张正向卡片，无旋转；卡片 584 × 452，文字 64 px，左右各 68 px 留白 |
| 页脚 | “更新于 日期 时间”，32 px，表示本机画面生成时间 |

便签文字区域宽 448 px，每行 7 个汉字、共 4 行。英文数字按半字宽；换行也占行。
网页输入框使用 26 px 字号、相同的七字折行规则，窄屏改为单列，不随窗口任意拉宽。
编辑字体与设备点阵字体不同，实际笔画以右侧共享绘图预览为准。

## 额度与横幅

百分比数字和进度条统一按四舍五入后的整数剩余额度绘制。缺失数据显示未知，
不推断为 100% 或无限；不同额度分组不能相互配对。

横幅选择分数 = 原始剩余额度百分比 + 已知可用重置次数 × 100。
优先使用 5 小时窗口；确认仅有 7 天窗口时才改用 7 天。实际进度条不加重置次数。

| 分数 | 资源 | 文案 |
| --- | --- | --- |
| ≥70 | `sprint` | 站起来蹬！ |
| ≥30 且 <70 | `cruise` | 定速巡航 |
| ≥1 且 <30 | `snack` | 要吃辣堡 |
| <1 | `sleep` | 玛卡巴卡 |

未知重置次数不加分；额度不可用或无法确定窗口时显示中性等待状态。
缓存过期时保留已知画面并标注状态。即使整数百分比未变，跨越精确横幅阈值也会更新图片。

重置机会显示已返回的可用机会明细中最近的到期日期和时间。明细不完整时标注“已知最近到期”；
缺失字段显示“到期时间未知”，0 次显示“暂无重置机会”。仅明确无到期且明细完整时显示无到期限制。
数据来源明确不支持重置时，整个重置区隐藏，不显示为 0 次或未知。额度优先按实际分钟时长匹配，
旧缓存没有时长时才兼容原有窗口名称。非 5 小时／7 天窗口保留在详情页，不强行套用首页模板。

## 刷新策略

同日内容不变时保持画面与页脚时间，不因分钟变化或成功轮询刷新。日期、整数额度、
重置次数、便签、横幅或可见状态变化时生成新画面；设备再次比较像素哈希，相同则不驱动屏幕。
仍使用全屏灰度刷新，发生刷新时可能短暂闪黑；未实现局部刷新。

## 预览和修改

README 的四张预览覆盖单／双额度、四档横幅和有／无重置机会。
重新构建后运行 `bash scripts/build-previews.sh`，PNG 写入 `docs/assets/`，
中间帧仅保留在忽略的 `var/previews/`；全部使用示例数据，不读取账号或连接设备。

```sh
make build
bin/glance preview --output var/preview.png
bin/glance preview --variant missing-five --output var/weekly.png
bin/glance preview --variant stale --output var/stale.png
bin/glance preview --variant unavailable --output var/unavailable.png
bin/glance preview --variant banner-snack --output var/snack.png
bin/glance preview --page 1 --output var/details.png
```

预览使用固定示例数据，不读账号、不连接设备。页码从 0 开始，详情页位于各额度分组首页之后。
白色按键可在设备上翻页，触控尚未实现。

修改绘图后运行 `make test`，同步主机与固件的绘图兼容标识，重新生成固件和完整安装包。
不要为了更改便签内容重新刷机；便签在管理页保存即可。
