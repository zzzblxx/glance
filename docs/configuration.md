# 配置与数据安全

默认配置为 `~/Library/Application Support/Glance/config.json`，文件权限必须是 `0600`。
通过 `bin/glance init-config` 首次生成，凭据随机创建，不在仓库中提供真实配置样本。
便签应在 `http://127.0.0.1:8888` 编辑；其他字段手动修改后需要重启服务。

## 常用字段

| 字段 | 默认值或作用 |
| --- | --- |
| `provider` | `openai`，当前唯一实现的数据来源 |
| `device_model` | `e1003`，当前唯一实现的设备型号 |
| `transport` | `usb`，当前设备使用 USB 数据同步 |
| `usb_port` / `usb_device_id` | 由配对工具写入，两项应同时存在 |
| `preview_listen` | `127.0.0.1:8888`，仅允许回环地址 |
| `notes` | 四张便签；网页新编辑限制为 4 行 × 7 个汉字 |
| `banner_id` | `auto`，由额度选择内置横幅 |
| `privacy_mode` | `false`；设为 `true` 时不传任务标题，只传状态计数 |
| `codex_binary` | `codex` 或可执行文件路径 |
| `codex_home` | 用户的 `.codex` 数据目录 |
| `data_directory` | 默认应用目录，保存归一化状态与进程锁 |
| `quota_poll_interval` | `10m`，最短 `1m`；请求失败后约 30 秒重试 |
| `activity_poll_interval` | `30s`，允许 `5s` 至 `30s` |
| `renderer_binary` | 默认主程序同目录的 `glance-render` |
| `device_token` | 本地随机值，用于任务 ID 加盐；不通过 USB 发送 |

额度查询频率不是屏幕刷新频率。新一轮采集即使产生新观察时间，画面不变仍不会刷新。
原始小数额度保留，进度条与数字四舍五入到整数；横幅继续按精确阈值选择。

`GLANCE_DEVICE_TOKEN` 可临时覆盖配置中的 token，应用不会主动加载 `.env` 文件。
`.env.example` 只记录环境变量名，不是完整配置。正常安装无需手动设置 token。

## 兼容处理

旧配置省略 `provider`、`device_model` 时仍默认 OpenAI＋E1003，便签、凭据与配对不变。
填写尚未实现的来源或型号会报错，不会静默降级到当前实现。

安装程序会迁移此前的默认目录及默认端口，保留未知配置字段与外部自定义数据路径。
迁移遇到新旧目录并存或不安全的符号链接会停止，不自动猜测或合并。
传输层保留旧配置每条便签 160 字符的安全上限，但新编辑必须满足 28 个汉字宽度和 4 行限制。
旧内容不会自动删除；编辑超长旧内容时应手动缩短后保存。

源码仍含显式 `transport: "wifi"` 的旧版诊断路径及 `device_listen` / `font_path` 配置。
当前发布固件不使用这条路径，也不会连接 Wi-Fi；不要用它替代 USB 配对。

## 存储与隐私

- 默认运行目录保存配置、归一化缓存和锁，不保存原始会话正文。
- 非隐私模式可能缓存、显示任务标题。隐私模式在序列化前移除标题；手写便签不受该开关隐藏。
- 管理页只有便签编辑接口可写，使用同源检查、进程级令牌、请求大小限制与版本冲突检查。
- USB 数据不包含账号凭据、文件路径、任务 ID 或原始事件；USB 物理接入仍需可信。
- 浏览器预览不证明设备已在线刷新，设备离线时旧画面无法自行更新状态标签。
- 升级归档和出厂闪存备份可能包含敏感信息，应仅保存在可信本机目录，不上传仓库。
- 配置、私钥、`.env`、测试目录和构建产物已列入 Git 忽略规则；忽略规则不能清除已进入 Git 历史的秘密。

应用不会阻止 Mac 睡眠，也不会修改系统安全设置。卸载保留配置和用户数据，
如需彻底销毁数据，应先确认备份与具体目录，再单独处理。
