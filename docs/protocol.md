# USB 数据协议

当前协议版本为 `2`，绘图兼容标识为 `glance-3`。主机与设备必须匹配兼容标识；
只更新一端可能导致连接被拒绝。应用版本另见根目录 `VERSION`。

## 连接与传输

E1003 外置 USB 串口连接 UART1，RX GPIO44、TX GPIO43，115200 baud。
Mac 只打开配置中明确配对的串口，并检查设备返回的 12 位十六进制 ID。
这属于物理设备识别，不是加密身份认证；不要连接不受信任的设备。

一次同步流程：

1. 主机发送换行结尾的 JSON `hello`，携带 `protocol`。
2. 设备回复 `ok`、`op`、`protocol`、`device`、`id`、`renderer`，以及当前
   `snapshot`、`frame` SHA256 和 `page`。
3. 快照哈希相同则结束；不同则发送 `begin`，包含 `protocol`、`bytes` 和 `sha256`。
4. 收到 `ready` 后发送原始 JSON 字节，每块最多 1024 字节。非末块收到
   `chunk` 和累计 `offset` 后才继续。
5. 设备验证长度、SHA256 和数据结构，绘制候选画面；像素变化才刷新电子纸。
6. 成功后返回 `applied`，包含快照、画面哈希和页码。错误或失败不作为成功同步。

快照上限 192 KiB，主机接受的回复行不超过 2048 字节。超时、错误偏移、版本不符、
哈希不符和格式错误均终止当次同步。断线后后台服务重试，不无限阻塞。
完整字段验证以 `internal/protocol/`、`internal/transport/serial/` 和 `firmware/e1003/src/main.cpp` 为准。

## 快照内容

快照包含额度窗口、来源状态、重置机会、可验证任务摘要和显示字段。
显示字段包括标题 `title`、日期、星期、画面生成时间、四张便签和横幅资源 ID。
标题由来源提供，不在固件写死。重置状态 `unsupported` 与 0 次、未知分别处理。
字体、横幅和绘图代码已嵌入固件，USB **不发送图片、帧缓冲或字形**。

数据源区分新鲜、过期和不可用。未知额度、次数和到期时间不能用零或虚构时间替代。
到期时间可能只有日期或部分机会有日期，显示层保留这种不确定性。
隐私模式隐藏任务标题，但不会隐藏用户主动填写的便签。
快照不包含账号凭据、本机文件路径或原始事件内容。

## 布局与刷新

设备原生画布为 1872 × 1404，竖屏逻辑坐标为 1404 × 1872，Gray4（16 级灰度）。
首页按额度组展示，按键可以切换首页及详情页。触控和局部刷新未接入。

额度原始精度保留用于横幅档位判断；进度条和百分比按整数呈现。
用于画面变化判断的数据排除无显示意义的轮询时间和分钟变化，保留日期、实际内容和状态变化。
因此定期采集、USB 检查与物理刷屏不是同一件事。
页面内容变化时仍使用灰度全屏刷新，短暂闪黑属于这一刷新方式的表现。

本地绘图助手使用同一份 `firmware/e1003/include/dashboard.h` 和字体生成预览，
但预览代表准备同步的画面，不代表设备已经成功显示。

## 本机管理接口

管理服务默认只监听 `127.0.0.1:8888`。

| 路径 | 用途 |
| --- | --- |
| `/` | 状态、预览和便签编辑 |
| `/status` | 数据及设备同步状态 |
| `/frame.png` | 本地主页预览 |
| `/note-latin.ttf` | 输入框的内置半字宽英文字体 |
| `/api/notes` | 获取或保存四张便签 |

便签保存检查请求来源、令牌、版本和容量，拒绝过期覆盖；不要绕过管理页直接修改运行中配置。
服务保留的其他传输兼容代码不代表当前 USB 固件支持网络传输。
